# GeoTaste AI - Restaurant Location Intelligence System

## Cognifyz Technologies Machine Learning Internship

### Project Objective

This project performs geographical and business intelligence analysis on restaurant datasets using location-based analytics and AI-driven scoring techniques.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Folium

---

## Key Features

- Restaurant hotspot city analysis
- Customer satisfaction analysis by location
- Premium dining market intelligence
- AI-powered Geo Intelligence Scoring
- Interactive restaurant geo mapping
- Business intelligence visual analytics

---

## Visual Analytics Included

1. Top Restaurant Hotspot Cities
2. Top Cities by Restaurant Ratings
3. Premium Dining City Analysis
4. AI-Powered Restaurant Ranking
5. Interactive Geo Distribution Map

---

## AI Geo Intelligence Formula

Geo Intelligence Score combines:

- Restaurant Ratings
- Popularity (Votes)
- Premium Pricing

Formula:

Geo Score = 0.5(Rating) + 0.3(Votes) + 0.2(Price Range)
